# SauceDemo Test Plan

## Test Objective

The objective of this testing is to verify the core
functionality of SauceDemo, including Login, Products,
Shopping Cart, Checkout, and Logout.

The goal is to ensure that the main user flows work
as expected and that users can successfully complete
the shopping process.

## Scope

### In Scope

- Login
- Products
- Shopping Cart
- Checkout
- Logout

### Out of Scope

- User Registration
- Product Reviews
- Admin Panel
- Payment Gateway Integration
- Performance Testing

## Test Approach

| Testing Type | Purpose |
|---|---|
| Functional Testing | To verify that Login, Products, Shopping Cart, Checkout, and Logout work according to the requirements. |
| Smoke Testing | To verify that the main application features work correctly after a new build. |
| Regression Testing | To ensure that changes or bug fixes do not break existing functionality, such as Login, Cart, and Checkout. |
| Exploratory Testing | To explore the application and identify unexpected issues in user flows that may not be covered by existing test cases. |

## Entry Criteria

1. The SauceDemo test environment is available and stable.
2. Test cases and checklists are prepared and reviewed.
3. Valid test accounts and test data are prepared and available for testing.

## Exit Criteria

1. All planned critical test cases have been executed.
2. No open critical defects remain.
3. All test execution results have been documented.

## Test Environment

- Application: https://www.saucedemo.com/
- Platform: Web browser
- Test Account: standard_user

## Notes

This is a sample test plan created for QA practice.

It describes a proposed testing approach and does not
represent an official SauceDemo test plan.

The planned testing activities are not all necessarily
executed as part of this document.
