# BUG-002 — Blank Page During Checkout

## Summary

A blank page is displayed after clicking Continue
during checkout, preventing the user from completing
a purchase.

## Environment

- Application: Fictional e-commerce web application
- Platform: Desktop
- Browser: Chrome (version not specified)

## Preconditions

1. User is logged in.
2. Shopping cart contains one product.

## Steps to Reproduce

1. Open the shopping cart.
2. Click Checkout.
3. Fill in all required fields with valid data.
4. Click Continue.

## Expected Result

The application proceeds to the next checkout step
and allows the user to complete the purchase.

## Actual Result (Simulated)

A blank page is displayed after clicking Continue.

The user cannot proceed with checkout or complete
the purchase.

## Defect Classification

- **Severity:** Critical
- **Priority:** High
- **Reproducibility:** 100% (according to the scenario)
- **Status:** Not Reported (Simulated)
